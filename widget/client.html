Client Portal

This page hosts the authenticated support chat. It loads the same widget script with data-mode="client", which swaps in a sign-in panel and points the widget at the client API. The public prospect knowledge base is never queried from here.

Testing the flow locally

  1. Seed a client and a project:
    python -m app.seed_client --email you@example.com --company "Acme Ltd"
  2. Open the chat, enter that email, and request a sign-in link.
  3. Without an email provider configured, the API returns the token directly and the widget signs you in automatically.
  4. Ask about project status, deliverables, or say “I want to speak to my account manager” to trigger escalation.
