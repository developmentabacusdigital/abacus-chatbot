AI chatbot test page — click the chat bubble in the bottom-right corner to start.

Testing guide

  1. Start the backend: cd backend && uvicorn app.main:app --reload
  2. Open this page from the backend so the widget finds the API automatically
  3. Click the chat bubble and try:
    • "What services do you offer?"
    • "I need a website for my manufacturing company"
    • "Tell me about AI automation"
    • "I'd like to book a call"

Framer embed — public site

<script
  src="https://your-backend-url.com/widget/abacus-chat-widget.js"
  data-calendly-url="https://calendly.com/abacusdigital/discovery">
</script>

The widget points at whichever origin serves the script, so data-api-url is only needed when the backend lives elsewhere.

Framer embed — client portal page

<script
  src="https://your-backend-url.com/widget/abacus-chat-widget.js"
  data-mode="client">
</script>

Put this on the client portal page only. It renders a sign-in panel, talks to /api/client/*, and reads exclusively from the client knowledge base. Try it at client.html.
